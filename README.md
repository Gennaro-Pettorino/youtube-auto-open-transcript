# YouTube Auto Transcript

Automatically opens the transcript panel when you watch a video on YouTube.

## Features
- Opens the transcript automatically
- No AI, no external services
- Lightweight and fast
- Works directly with YouTube's native transcript

## How it works
This extension detects when a YouTube video loads and automatically clicks the "Show transcript" button when it becomes available.

## Installation

1. Download this repository as ZIP
2. Extract the folder
3. Open Chrome and go to:
   chrome://extensions/
4. Enable "Developer mode"
5. Click "Load unpacked"
6. Select the extracted folder

## Notes
- Works only on videos that have subtitles available
- If YouTube changes its interface, the script may need a small update
